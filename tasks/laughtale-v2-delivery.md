## 실행 계약 · LAUGH-V2-PRODUCT-001 / revision 2

예상 결과: 현재 V2 API/Gateway와 FE의 실제 진입·재접속·중복 병합·세션 폐기 동작이
구현/검증되고, 실패나 환경 장애는 정확한 근거로 남는다. 기존 5초 목표를 낮추지 않는다.
원문·기존 계약은 Laughtale tasks/linky-chat-internal-dm.md가 소유한다.

- 개발 소유: Laughtale의 관련 FE/BE·시험·제품 task. 실제 최소 변경만, 기존 dirty 변경 보존.
- 독립 QA: 기존 증거·코드 read-only 검토 후 변경 결과 검증. 제품 문서 동시 편집 금지.
- PM: 보드·범위·의존성·질문과 결과 처리. 준비 확인·수정 배정에 반복 사용자 승인 금지.
- 허용: 기존 승인된 로컬 V2 제품 구현·관련 회귀·기존 전용 실험 환경의 제한 검증.
- 제외: 다른 프로젝트 변경/종료, 공유 PG 인스턴스 신규 생성·업그레이드, 데이터 삭제,
  실제 외부 provider·제품 배포·광고·메시지·새 유료 API·무제한 주기 실행.
- 자원: 제품 task와 코드 writer는 개발 단독. DB/클러스터/브라우저 검증은 동시 실행하지 않고
  기존 대상·자원 여유·활성 작업을 확인한다. 무확인 부하 재시작 금지.
- 한도: 각 실행 20분 체크포인트, 실패 시 같은 원인의 자동 재시도 최대 1회 후 PM 판단.
  한도는 관측 체크포인트이며 자동 중복 기동/강제 종료가 아니다. 완료나 실제 장애까지 추적한다.

기존 ORC-12의 반복 문서 작업은 최소 증거 대조로 종료하고 해당 선행을 해제한다.
PATH의 경로 준비 부분은 PRODUCT 실행에 포함해 확인하며 전체 부하 비교 완료와 혼동하지 않는다.
기준/권한 변경은 revision 2의 별도 hash로 연결하고 이전 후보 hash를 승인 증거로 재사용하지 않는다.

## 실행 기록

- PM이 ORC-12의 증거 대조를 완료하고 ORC-17 PRODUCT를 실행 중으로 전환했다.
- 개발과 QA를 별도 Orca 실행으로 배정했다. 둘 다 기본 Astra로 기동된 사실을 확인했다.
  난이도에 따른 선택 근거가 없었던 배정이며, [모델 선택 조사](model-routing.md)에 교정을 기록했다.
- 개발은 관련 FE/BE 수정 후 FE 47개·BE 353개 검사, build/type/lint 통과를 보고했다.
  이 숫자는 개발 보고이며 최종 독립 QA 판정과 별개다.
- QA가 HTTP/WS 단일 진입점, 엄격한 5초 세션 폐기와 7초 관찰 예산의 혼동을 지적했다.
  PM은 개발에 전달하고 자연 만료·재로그인 측정 시작점을 구분하도록 했다.
- 기존 전용 실험 환경의 Gateway 변경 검증은 개발 단독 writer로 진행한다.
  QA는 최종 파일·증거 인계와 PM의 검증 자원 해제를 기다린다.
- 기존 부하 sampler의 Fanout 2개 조건과 현재 기능 검증 환경의 1개가 달랐다.
  PM은 replica를 늘리거나 기존 부하 기준을 낮추지 않고, 현재 topology에 맞춘 별도 기능 검증
  preflight를 허용했다. 메모리·OOM·활성 writer·readiness·DB 연결 guard는 유지한다.
- runtime에 저장된 초기 문서 SHA는 실행 계약을 전달한 당시 snapshot을 식별한다.
  이후 이 실행 기록을 추가한 파일 전체 SHA와 혼동하지 않는다. 기준 P1–P4는 변경하지 않았다.

최종 브라우저 결과·독립 QA 판정·종료 처리는 아직 대기 중이다.

## 사용하지 않는 agent 정리 · 2026-09-10

사용자가 완료·미사용 agent 종료를 요청했다. Orca의 정확한 Laughtale workspace에서
이전 메인·디자인·PM 인계·설계 검토 4개 세션의 idle을 확인하고 종료했다.
디자인 세션의 남은 Pen CLI 두 개는 /stop으로 정리한 후 agent terminal을 닫았다.
4개 close 응답 모두 ptyKilled=true이며 재조회에서 사라졌다.
진행 중인 V2 개발·QA 2개와 FE·대시보드·포트포워딩은 유지했다. 파일·디자인 원본은 변경하지 않았다.

개발 최신 보고: 브라우저 split routing/reconnect/중복 렌더 검사와 revoke 1780.7ms,
별도 revoke 2510ms·자연 만료 상한 1963.99ms 및 이전 cookie HTTP401/WS403 통과.
마지막 sender lease guard 수정 후 최종 image·증거를 인계할 예정이며, 아직 독립 QA 통과로 보지 않는다.
